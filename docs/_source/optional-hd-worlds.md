# Optional HD Worlds for Cyanescent Player V1

Requires Cyanescent Player **Pro Video 1.0.0 (build 2)** from the final V1 release, or a later compatible Pro Video release. Free and Pro cannot load HD Worlds.

Available Worlds: Red Cage Stinkhorn (360), Apollonian Physarum Genesis (390), Newton Basin Descent V1 (392), Newtons Law (393), Artificial Consciousness (394), and Helix Tunnel (395).

The installation note inside these previously prepared DMGs refers to an “HD Compatibility” Player candidate. The final Pro Video V1 release above supersedes that candidate; use the final release. The original ZIP INSTALL.txt also describes older packaging. Follow this README for the current release.

Quit Player. Open the desired World DMG, launch its Installer app, and select your final Pro Video application if prompted. Install each World separately. Only explicitly replace a World when you intend to replace that installation; the installer preserves a private backup. Eject the DMG afterwards.

Worlds are stored in `~/Library/Application Support/Cyanescent Player/HD Worlds/`. Compatible Player upgrades preserve these installations. Keep every World folder intact. The final Player controls factory calibration; no media update is required.

Verify installer downloads with `shasum -a 256 -c SHA256SUMS.txt`. Only the six self-contained DMGs are hosted here; no separate ZIP is required.
